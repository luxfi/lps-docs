## Abstract

Quasar is a novel consensus protocol achieving sub-second finality through optimistic execution and rapid Byzantine agreement.

## Motivation

Current blockchain consensus mechanisms trade off between decentralization, security, and speed. Quasar achieves all three.

## Specification

### Phases

1. **Photon**: Leader selection via VRF
2. **Wave**: Proposal propagation
3. **Focus**: Vote aggregation
4. **Prism**: State commitment
5. **Horizon**: Finality confirmation

### Performance Targets

- Block time: 250ms
- Finality: 500ms
- Throughput: 10,000+ TPS

## Security Considerations

Byzantine fault tolerance up to 33% of stake.
